# Optional audio

Put these files here to turn on sound. Any that are missing are skipped and the game plays silently.

| File | Used for |
|---|---|
| `bgm_chill.mp3` | Background music (loops) |
| `sfx_button.mp3` | Menu / dialogue clicks |
| `sfx_jump.mp3` | Jumping |
| `sfx_powerup.mp3` | Toggling Spirit Sight |
| `sfx_collect.mp3` | Picking up a relic |
| `sfx_win.mp3` | Ending |
